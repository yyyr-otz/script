修改env文件内的参数
由于游戏机平台，上传文件的时候名称为.env无法选中

所以先上传env文件，再点击文件后面的三个点，Rename，修改文件名为.env


说明文件不上传，只上传，app.py,requirements.txt,env三个文件，点击控制台的start即可。
